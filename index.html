About this page

This is the home page of my example case project for ITC 2400. It is deliberately plain: the purpose of this stage is to show that a valid HTML5 document has been created, linked to an external stylesheet and published live, not to show styling technique.

The page is published with GitHub Pages and is available at https://wyhtjw.github.io/itc2400-module1/.

What is in this package

  • index.html — this home page
  • template.html — the empty template that every later page in the project will be built from
  • css/style.css — the external stylesheet shared by both pages
  • readme.txt — notes on how the files fit together
