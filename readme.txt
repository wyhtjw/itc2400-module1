Notes
-----
Every page uses the same skeleton: header, nav, main, footer. The nav is a plain
unordered list of relative links so that adding a page means adding one list item
on every page. There are no inline styles and no JavaScript; all presentation is
in css/style.css. File and folder names are lowercase with no spaces so that the
site behaves identically on GitHub Pages, which is case sensitive.
